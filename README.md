# Splunk Mitre Detection Lab
This project simulates and detects adversary behavior using Splunk and maps it to the MITRE ATT&CK framework.


**Lab Workflow Overview** 

1. Log ingestion from Ubuntu using auditd/Sysmon
2. Detection of specific MITRE techniques
3. Query building in Splunk
4. ATT&CK mapping
5. Dashboards and visualizations


**Environment** 

- **Host OS**: Ubuntu 
- **Log Collection Tools**: auditd or Sysmon for Linux
- **SIEM Platform**: Splunk 
- **Scripting/Automation**: Bash
- **Attack Simulation**: Atomic Red Team
